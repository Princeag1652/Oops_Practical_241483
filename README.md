## Repository Overview

This repository contains all major **OOPS Lab Experiments** implemented in **C++** as part of academic practical coursework. These programs demonstrate the core principles of Object-Oriented Programming such as:

* Functions
* Constructors
* Inheritance
* Polymorphism
* Operator Overloading
* Static Members
* Containership
* Menu-Driven Systems
